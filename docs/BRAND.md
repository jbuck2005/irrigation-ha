# Brand guide

The drop joins the two halves of the project: a plant on the left, a circuit on the right, sharing one stem. The amber node is the valve the controller is switching.

All graphics and colour files are generated by [`brand/build_brand.py`](brand/build_brand.py). Change the palette there and run it from the repository root, rather than editing the output. The panel keeps its own copy of the colours in `custom_components/irrigation/frontend/irrigation-panel.js`, so update that file too.

## Colours

| Colour | Hex | Use |
| --- | --- | --- |
| Deep Slate | `#121C2B` | Dark foundation, text contrast and UI containers |
| Botanical Green | `#2C5E43` | Foliage health, eco and soil metrics, moisture status |
| Balanced Vivid Blue | `#0284C7` | Primary interactive accent, valve active state, HACS badge |
| Sunburst Amber | `#F59E0B` | Warning thresholds, solar and evapotranspiration alerts, highlights |

Two tints keep status colours readable on dark surfaces:

| Tint | Hex | Why |
| --- | --- | --- |
| Green on dark | `#4CAF7D` | Botanical Green is only 2.3:1 on Deep Slate |
| Blue on dark | `#38BDF8` | Lifts Vivid Blue from 4.2:1 to 6.8:1 for status text |

Contrast rules:

- White on Botanical Green is 7.5:1, so it suits any text size.
- White on Vivid Blue is 4.1:1, so keep it to bold or large text, such as badges and buttons.
- Put Deep Slate text on amber, never white. White on amber is only 2.2:1.

## Usage

- Write the project as `irrigation-ha` in the logo, and **Irrigation Controller** in Home Assistant and in prose.
- Keep the tagline as `SMART IRRIGATION TECH`.
- Do not recolour, rotate or stretch the drop, and do not add a badge to it.
- Keep clear space around the logo of at least a quarter of its height.
- Below 24 px, use the icon alone. The logo needs at least 48 px of height for the tagline to stay legible.
- Do not use the Home Assistant logo or imply that this project is official. Naming Home Assistant in plain text is fine.
- Say "HACS compatible" only in the badge style shown on the banner. Keep the badge off the logo and icon.
- The zone cards on the banner are an illustration of a watering cycle, not a screenshot.

## Type and tone

Text uses [Poppins](https://github.com/itfoundry/Poppins): Bold for the wordmark and labels, Regular for the tagline. It is licensed under the SIL Open Font License, and the font files and licence are in [`brand/fonts/`](brand/fonts/).

Write plainly and practically. This software controls real valves, so state what it does and avoid hype.

## Lovelace colours

[`brand/irrigation-theme.yaml`](brand/irrigation-theme.yaml) is a Home Assistant theme with light and dark modes. It needs no custom cards. It recolours the page background, cards, header, icons and active states across all your dashboards, not only the irrigation one.

1. Copy it to `/config/themes/`.
2. Add this to `configuration.yaml` and restart:

   ```yaml
   frontend:
     themes: !include_dir_merge_named themes
   ```

3. Select **Irrigation** in your user profile, or on a single dashboard view.

The theme defines these variables, and the role variables switch to the lighter tints in dark mode:

| Variable | Role |
| --- | --- |
| `--irrigation-slate`, `--irrigation-green`, `--irrigation-blue`, `--irrigation-amber` | Core palette |
| `--irrigation-valve-active-color` | A zone is running |
| `--irrigation-moisture-color` | Moisture and soil status |
| `--irrigation-warning-color` | Warnings and highlights |

To use them on a single card you need [card-mod](https://github.com/thomasloven/lovelace-card-mod), which is a separate install:

```yaml
type: tile
entity: valve.irrigation_zone_1
card_mod:
  style: |
    ha-card {
      --tile-color: var(--irrigation-valve-active-color);
    }
```

[`brand/irrigation-colors.css`](brand/irrigation-colors.css) has the same variables for a custom card's stylesheet. It has no dark mode, so use the `-on-dark` variables on dark surfaces.
