# Security policy

This integration controls real water valves, so please report security problems privately rather than in a public issue.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting: go to the [Security tab](https://github.com/jbuck2005/irrigation-ha/security), then **Report a vulnerability**. Only the maintainer can see the report.

Please include:
- What the problem is and how it could be used
- Steps to reproduce it
- The integration, Home Assistant and `irrigationd` versions

Never include a real token, host name or address from your own setup. Use `your-long-random-token` in examples.

Problems in the daemon itself belong in [irrigationd](https://github.com/jbuck2005/irrigationd/security).

## Supported versions

Only the latest release gets fixes.

## What happens next

This is a one-person project, so replies can take a few days. You'll hear back whether the report is accepted, and a fix will be released before the problem is described in public.
